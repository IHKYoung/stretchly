# Pauza 0.1.5

这一版把“少打扰，但别忘了照顾自己”往前推了一步：设置更简单，提醒更懂得等一个自然空档，休息时看到的那句话也更像人说的了。

## 这一版有什么

- 设置首页现在直接呈现三档休息节奏与常用选项，也保留清楚的自定义入口，不再需要穿过一层“详细设置”。
- 新增少打扰、均衡、多活动三档节奏；新安装默认采用均衡档，已有设置会原样保留。
- 智能提醒等待自然空档时，菜单栏会显示真实的最长等待倒计时；相关提示不再提前承诺“立即开始”。
- 微休息与完整休息提示语各扩充一倍：官方简中、繁中与英文现在分别包含 `728` 条微休息和 `488` 条完整休息提示。
- 新提示语覆盖工作调侃、身体观察、轻量健康知识、情绪关照、日常场景与小任务；完整休息会用更从容的口语段落陪你真正离开椅子一会儿。
- 完整休息提示语完整显示后会停留 `60` 秒，减少刚看完就切走的匆忙感。

## 兼容性

- 本次提供 macOS Apple Silicon 安装包。
- 已有用户的持久化休息节奏不会被自动迁移；不匹配预设时会继续显示为“自定义”。

下载 `Pauza_0.1.5_aarch64.dmg`，打开后将 Pauza 拖入“应用程序”即可。
