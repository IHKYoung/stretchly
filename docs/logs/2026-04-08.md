- Goal: 修复 macOS 菜单栏 tray icon 发糊且偏大、Dock icon 偏大的问题，并让图标资源脚本可稳定重生成。

- Assumptions: 用户主要反馈来自 macOS Retina 环境；当前终端未授予 Screen Recording，故无法采集系统级菜单栏 / Dock 截图，只能以资源预览、源码依据和构建验证完成本轮闭环。
